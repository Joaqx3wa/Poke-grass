# PokéGrass v0.1.3 Beta

- Corregida la selección de Megas para especies con varias formas. Ahora el menú de Charizard muestra directamente **Mega Charizard X** y **Mega Charizard Y**; Mewtwo, Lucario y Raichu también ofrecen todas sus formas registradas como opciones directas.
- Se conserva la megaevolución de variantes femeninas corregida en 0.1.2, así como el balance de recompensas y el guardado de todos los shiny.
- Añadida una comprobación completa de las 52 formas Mega registradas: selección del menú real, carga de sprites, transformación, persistencia y desmegaevolución, para variantes normales, shiny, Alfa y femeninas disponibles. Las especies con varias Megas se prueban recorriendo todas sus formas con el mismo ejemplar.

Descarga **PokeGrass-win-Setup.exe** para instalar o actualizar, o utiliza el buscador de actualizaciones del juego.
